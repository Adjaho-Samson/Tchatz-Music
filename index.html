Installer Tchatz Music

Ajoute ton lecteur à l’écran d’accueil.

  1. Ouvre ce site dans Chrome sur Android.
  2. Dans le menu du navigateur, choisis « Installer l’application » ou « Ajouter à l’écran d’accueil ».
  3. Confirme pour lancer Tchatz Music en plein écran.

L’installation nécessite un hébergement HTTPS compatible. Le panneau d’aperçu Arena peut limiter l’installation directe.

Vie privée

Pas de compte, pas de serveur, pas d’envoi audio.

Tchatz Music ne peut accéder qu’aux fichiers que tu choisis dans le sélecteur Android. L’import crée une copie locale dans le stockage du navigateur ; le fichier d’origine n’est pas modifié. Les données de navigateur peuvent être effacées par le système ou lors d’un nettoyage : garde tes fichiers originaux.

Données de l’application

Retire les fichiers importés ou réinitialise tes préférences.

L’effacement des données supprime définitivement la bibliothèque Tchatz Music de ce navigateur. Cela ne supprime pas les originaux du téléphone.
